## Что сохранено

Четыре класса героя: воин, следопыт, маг, паладин.
Четыре локации: лес, болото, склеп, логово дракона.
Есть пошаговый бой с критическими ударами, опыт, уровни, золото, добыча,
зачарования, смена оружия и брони, покупка и продажа предметов.

Дополнительное задание: паладин получает молот и освящённую броню;
в болоте живёт новый противник, который оставляет новое оружие и броню.
Цель — победить дракона. Начните с леса, затем улучшайте снаряжение и переходите в склеп.

Перед экспедицией здоровье восстанавливается. При поражении теряется половина золота,
округлённая вниз. Экипированные предметы нельзя продать; после замены они попадают в инвентарь.
Продажа приносит половину цены. Прогресс хранится в памяти до завершения программы.

Можно ввести целочисленный сид или оставить поле пустым.
Повторяемость гарантируется при одинаковых сиде и исходном состоянии героя.
Повторить сид после смены снаряжения или повышения уровня — другой эксперимент.

Архитектура сохранена, но убраны отдельные файлы для каждого enum, записи и короткого класса,
многочисленные свойства, возвращающие единственное поле, и вложенные пакеты.
Состояние героя представлено dataclass. Предметы сравниваются по идентичности:
два одинаковых меча в инвентаре остаются двумя отдельными предметами.

## Соответствие требованиям

- Singleton: Dice.__new__ возвращает единственный экземпляр.
- Builder: HeroBuilder собирает героя через цепочку шагов и проверяет данные в build.
- Factory Method: абстрактный Location.create_enemy переопределён четырьмя локациями.
- Abstract Factory: StarterKitFactory имеет два метода, create_weapon и create_armor;
  четыре реализации создают разные семейства снаряжения.
- Prototype: Item.copy сохраняет конкретный класс предмета и копирует изменяемый список зачарований.
- demo.py показывает каждый паттерн в консоли; main.py запускает самостоятельную игру.

17 тестов проверяют правила игры и паттерны. Тест полного прохождения начинает с героя
первого уровня и проверяет победу над драконом отдельно для каждого из четырёх классов.
Фактический вывод тестов сохранён в verification.txt.
