## Запуск в PyCharm

Откройте проект tech-prog-2026, раскройте lab4 и запустите main.py зелёной кнопкой Run.
Отдельные XML-конфигурации запуска удалены как необязательные.
Окружение .venv в корне проекта используется PyCharm и сохраняется.

- main.py — игра;
- demo.py — демонстрация всех семи паттернов без ручного ввода;
- test_game.py — проверки;

Из терминала в папке lab4:

```console
python main.py
python demo.py

```

## Требуемые паттерны

| Паттерн | Реализация |
|---|---|
| Decorator | world.py: EnemyDecorator, LegendaryEnemy, WindfuryEnemy, ArmoredEnemy |
| Proxy | storage.py: CachingHeroRepository поверх FileHeroRepository |
| Adapter | world.py: HauntedWeapon превращает оружие в противника |
| Facade | game.py: GameFacade управляет игрой и сохранениями |
| Strategy | combat.py: BalancedTactic, AggressiveTactic, CautiousTactic |
| Observer | game.py: GameEventPublisher, AchievementTracker, ExpeditionJournal |
| Chain of Responsibility | combat.py: EvasionHandler, ArmorHandler, BarrierHandler |

Игра продолжает третью лабораторную: сохранены её порождающие паттерны,
четыре класса героя и прежние локации. Добавлены проклятый особняк,
усиления врагов, тактики, цепочки защиты, достижения, журнал и сохранения.
Все 10 Python-файлов находятся прямо в lab4.

## Сохранения

Файл heroes.json создаётся рядом с main.py и хранит нескольких героев.
После создания героя, боя, покупки, продажи и экипировки прогресс сохраняется автоматически.
Начальное меню позволяет продолжить игру. При загрузке герой отдыхает в лагере:
восстанавливаются здоровье и защита. Снаряжение, зачарования, опыт, золото и достижения сохраняются.
Журнал содержит экспедиции текущего запуска и отдельно в JSON не записывается.
Повреждённое сохранение не перезаписывается автоматически; запись использует временный файл и os.replace.
Кэш работает внутри одного процесса, внешние правки файла видны после перезапуска.

36 тестов проверяют механику, все паттерны, сохранения и прохождение до дракона
всеми четырьмя классами с повторной загрузкой. Результат — verification.txt.
Демонстрация и тесты не изменяют пользовательский heroes.json.
